# 6-step Problem Solving Approach

1. Restate the problem
2. State Brute force approach
3. Identify bottleneck
4. Propose Optimal solution. Ask "does that approach make sense?" and get explicit buy-in before you start typing.
5. Code Optimal solution and Narrate: Write the optimal solution and talk through every non-obvious decision as you go. DO NOT keep quiet while narrating your solution
6. Test edge cases. Close by stating complexities clearly
