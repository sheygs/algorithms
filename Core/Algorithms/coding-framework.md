# Live Coding Interview Framework

A structured, repeatable 6-step approach to tackling algorithmic problems during technical interviews.

## The 6-Step Process

### 1. Restate and Clarify

Articulate the prompt in your own words to confirm understanding. **Before moving forward, you must ask clarifying questions regarding input size, constraints, edge cases, and data quality.** Wait for the responses and use those details to shape the rest of your approach.

### 2. Define the Brute Force Approach

Outline the most straightforward, naive solution. This establishes a working baseline and proves you can solve the problem before worrying about optimization.

### 3. Identify Bottlenecks

Analyze your brute force logic to pinpoint inefficiencies, redundant work, or specific areas where time and space complexities are dragging.

### 4. Propose the Optimal Solution

Pitch your refined approach. Clearly explain the updated logic and explicitly ask, _"Does this approach make sense?"_ Secure complete buy-in from the interviewer before touching the keyboard.

### 5. Code and Narrate

Write the optimized implementation in Python 3 while continuously "thinking out loud."

- **Implementation Rules:** Place the time and space complexity directly at the top of the code. Skip pseudocode entirely and go straight to the optimized solution.
- **Narration:** Proactively explain non-obvious decisions, data structure choices, and logic flows as you type—never code in silence.

### 6. Test and Conclude

Walk through the completed code using edge cases and standard inputs to verify its correctness. Close the session by clearly restating the final complexities.
