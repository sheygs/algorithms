# Contains Duplicate

## 📌 Problem Description

Given an integer array `nums`, return **`true`** if any value appears **more than once** in the array. Otherwise, return **`false`** if all elements are distinct.

---

## 🧠 Topics

- Arrays
- Hash Tables
- Sorting

---

## 📝 Examples

### Example 1

```text
Input: nums = [1, 2, 3, 3]
Output: true
Explanation: The value 3 appears more than once.
```

### Example 2

```text
Input: nums = [1, 2, 3, 4]
Output: false
Explanation: All elements are distinct.
```

### Example 3

```text
Input: nums = [1, 1, 1, 3, 3, 4, 3, 2, 4, 2]
Output: true
Explanation: Multiple values appear more than once.
```

---

## 📋 Constraints

- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

---

## 🎯 Objective

Design an algorithm that efficiently determines whether the array contains duplicate elements.

**Recommended Time Complexity:** `O(n)`
**Recommended Space Complexity:** `O(n)`
