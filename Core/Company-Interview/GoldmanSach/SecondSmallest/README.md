# Second Smallest Element

Given an array or list of numbers, identify the **second smallest** distinct value. Implement the algorithm in linear time complexity O(n) using a single-pass approach

## Example

- **Input:** `[3, 1, 4, 1, 5, 2]`
- **Smallest:** `1`
- **Second Smallest:** `2`

## Performance

- **Time Complexity:** O(n) — The list is traversed exactly once.
- **Space Complexity:** O(1) — Only two variables are stored in memory regardless of input size.
